# Atualização dos perfis de egressos

Este pacote contém somente os arquivos necessários para atualizar os perfis de Maria Eduarda Morais Santos Costa, Igor Roberto de Almeida Moreira e Cássia Caren Santana Teixeira, os respectivos cartões da página de egressos e o Mapa dos Egressos.

## Como aplicar pelo GitHub Desktop

1. Extraia o ZIP.
2. Copie as pastas `assets`, `data` e `pages` para a pasta local do repositório `20conversas`, aceitando a substituição dos arquivos existentes.
3. No GitHub Desktop, confira a lista de alterações e a prévia das diferenças.
4. Crie o commit e publique quando estiver satisfeito com a revisão.

Nenhuma alteração foi enviada diretamente ao GitHub durante a preparação deste pacote.
