CORREÇÃO DEFINITIVA DAS CAPAS – PRODUÇÃO

Este pacote corrige o problema de cache do pacote anterior.

O que muda:
- cria data/producao-docentes-v2.js (novo nome, para o navegador não reutilizar a base antiga em cache);
- pages/producao.html passa a carregar a base v2;
- script.js passa a carregar a base v2 nas páginas individuais dos professores;
- todas as 37 capas enviadas por você ficam locais em assets/producao/capas/;
- os caminhos das imagens locais recebem ?v=2 para evitar cache de erros 404 antigos.

COMO INSTALAR:
1. Extraia este ZIP na raiz do repositório 20conversas.
2. Confirme a substituição de pages/producao.html e script.js.
3. Mantenha/adicone a pasta data e assets conforme o ZIP.
4. Commit e Push origin no GitHub Desktop.
5. Aguarde a publicação do GitHub Pages. Não é necessário apagar os arquivos antigos.

Se uma capa ainda não aparecer depois desta correção, o problema não será mais cache/base antiga: será possível identificar exatamente qual arquivo individual está faltando no repositório.
